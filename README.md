# Ficha de Pré-Venda — Horto Ville III

Página estática da ficha profissional de pré-venda, pronta para publicação no GitHub Pages.

## Publicar

1. Crie um repositório no GitHub e envie os arquivos desta pasta para a raiz do repositório.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch principal e a pasta **/(root)**, depois salve.
5. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

A ficha funciona como uma página HTML independente. Os dados preenchidos ficam salvos no armazenamento local do navegador usado para preencher a ficha.
