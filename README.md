# Ficha Interativa de Pré-Venda — Horto Ville III

Versão completa para publicar no GitHub Pages, sem conexão com banco de dados e sem envio dos cadastros a um servidor.

## Arquivos

- `index.html`: ficha interativa.
- `.nojekyll`: permite publicação simples pelo GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html` e `.nojekyll` para a raiz do repositório. O nome da página precisa ser `index.html`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

## Dados preenchidos

A ficha salva o preenchimento no armazenamento local do navegador e dispositivo usados pela pessoa que a preenche. Os dados não são enviados ao GitHub, ao corretor nem a um banco de dados. Para compartilhar o cadastro, use a opção de salvar/ imprimir em PDF e envie o arquivo com cuidado.

O preenchimento salvo localmente não é compartilhado entre navegadores ou dispositivos. Para limpar os dados locais da ficha, use o botão **Limpar formulário**.
